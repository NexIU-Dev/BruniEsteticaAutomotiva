# Bruni Estética Automotiva

Landing page estática da Bruni em São José dos Campos, feita com Astro e CSS próprio.

## Rodar localmente

```bash
npm install
npm run dev
```

Para conferir a versão de produção:

```bash
npm run check
npm run build
npm run preview
```

O build fica em `dist/`. Para hospedar em um subdiretório, defina `SITE_BASE` antes do build (por exemplo, `/BruniEsteticaAutomotiva/`). Configure o domínio e a URL canonical quando a hospedagem for definida.

As fotos aprovadas estão em `public/images/`; origens e limitações em [ASSET_SOURCES.md](ASSET_SOURCES.md). A direção e os critérios de aceite estão em [PLANO_IMPLEMENTACAO.md](PLANO_IMPLEMENTACAO.md).
